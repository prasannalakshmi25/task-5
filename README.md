# Student Management App 🎓

A professional Student Management App built using Kotlin and Jetpack Compose during my Android App Development Internship at Apex Planet Software Pvt Ltd.

## 🚀 Features
- Add Student Details
- Display Student List
- Delete Student Records
- Modern UI Design
- User-Friendly Interface

## 🛠️ Technologies Used
- Kotlin
- Jetpack Compose
- Android Studio

## 📱 Project Overview
This application helps manage student information in a simple and organized way. Users can add student details such as name, roll number, and department, view the student list dynamically, and delete records easily.

## 🎯 Learning Outcomes
- Android UI Development
- Jetpack Compose Basics
- State Management
- LazyColumn Usage
- User Input Handling
- Dynamic List Management
